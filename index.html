03 — About

One developer, full stack

I'm Muhammad Naeem, an independent developer working under the NaeemHCK handle. I design and build AI-powered web products end to end — from the model integration layer down to the last easing curve.

My current main build is a conversational house-planning platform: an AI that turns plain-language requirements into code-compliant floor plans with live cost estimates. Around it, I ship cinematic web experiences and open-source UI work.

Operating principle: never treat every feature as an AI problem — LLMs understand intent, deterministic engines handle geometry, constraints, and money.
